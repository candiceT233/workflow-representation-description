# Agentic Prompt Pack

Status: v3 draft for review before future evaluations.

This directory contains controlled prompts and allowed-input manifests for the
two currently active workflows:

- Montage 30GB
- 1000Genome 10 chromosomes

Each fresh agent should receive exactly one prompt file and the matching
allowed-input manifest. The purpose is to keep the experiment controlled: the
workflow, scale, candidate deployment choices, runtime definitions, validation
requirements, and output contract stay fixed, while the agent's available
information changes by setup.

Version 3 uses a decision-only protocol. A fresh agent selects one deployment
from the allowed inputs. A neutral executor, not the agent, submits the workflow
job, validates outputs, measures runtime, and records cleanup.

## Directory Layout

```text
prompts/
  montage_30gb_<setup>_prompt.md
  1000genome_10chr_<setup>_prompt.md

manifests/
  montage_30gb_<setup>_allowed_inputs.yml
  1000genome_10chr_<setup>_allowed_inputs.yml

baseline_specs/
  montage_30gb_baseline_execution_spec.md
  1000genome_10chr_baseline_execution_spec.md

bundle_builder_specs/
  montage_30gb_<setup>_bundle_builder_spec.md
  1000genome_10chr_<setup>_bundle_builder_spec.md

neutral_executor_specs/
  montage_30gb_<setup>_neutral_executor_spec.md
  1000genome_10chr_<setup>_neutral_executor_spec.md
```

Active agentic setups for the current rerun:

- `code_only`
- `code_dpm`
- `dpm_only`
- `wdd_pair_only`
- `wdd_pair_dpm`

Deferred setups retained for later prompt review, but not active in the current
rerun:

- `wdd_full_only`
- `wdd_full_dpm`

Baseline is not an agentic setup. It is a deterministic BeeGFS reference
procedure documented under `baseline_specs/`.

## Use Protocol

For each agentic setup:

1. Start a fresh agent session.
2. Give the agent only the matching prompt and manifest.
3. Build the clean input bundle using the matching
   `bundle_builder_specs/*_bundle_builder_spec.md`.
4. Place or expose only the clean input bundle files listed as allowed in the
   manifest.
5. Do not provide prior setup results, chat conclusions, or report summaries.
6. Require the agent to write a deployment decision report.
7. Run the selected deployment with the matching
   `neutral_executor_specs/*_neutral_executor_spec.md`.
8. Save the exact prompt, manifest, bundle inventory, tool list, decision
   report, executor commands, timing, validation, and cleanup status in the run
   report directory.

For baseline, use the matching `baseline_specs/*_baseline_execution_spec.md`.

The decision agent must not submit Slurm jobs, execute workflow scripts, make
live Widget MCP calls, use web access, or call subagents unless a future prompt
version explicitly changes those constraints.

## Regeneration

The prompt pack is generated by:

```bash
python workflow_representation_experiments/docs/agentic_prompt_pack/generate_prompt_pack.py
```

Edit the generator if the common prompt structure or setup definitions change,
then regenerate the prompt files and manifests.
